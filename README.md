🏦 [Classe + Objeto, Sistema De Controle De Ar Condicionado]

> Status do Projeto: 🏁 Concluído 

Uma aplicação desenvolvida para simular um sistema de controle de Ar Condicionado permitindo ligar/desligar, aumentar e diminuir temperatura, trocar modo, aumentar e diminuir a velocidade e mostrar o status.

---

## 🚀 Funcionalidades

- [x] Ligar/Desligar
- [x] Aumentar temperatura
- [x] Diminuir temperatura
- [x] Trocar modo
- [x] Aumentar velocidade
- [x] Diminuir velocidade
- [x] Mostrar status

---

## 🛠️ Tecnologias Utilizadas

- Linguagem: Java
- Paradigma: Programação Orientada a Objetos (POO)
- IDE / Editor: VS Code
- Controle de Versão: GitHub
